# Local-Only Files (not in git, on disk only)

These files exist on disk but are not tracked by git. They fall into three categories:
**benchmark data** (regenerable from scripts), **other experiments** (from earlier
NEUROSCOPE development runs on unrelated datasets), and **auto-generated run outputs**
(regenerated every time NEUROSCOPE runs).

---

## 1. Benchmark Expression Data — `converted/<dataset>/`

Generated by the `scripts/prep_*.py` scripts. Gitignored by design (large).

| Directory | Size | Contents | Regenerate with |
|-----------|------|----------|----------------|
| `converted/kang2018/` | ~50 MB | Kang 2018 expression matrix + metadata | `python scripts/prep_kang2018.py` |
| `converted/covid_atlas/` | ~120 MB | COVID Blood Atlas expression + metadata | `python scripts/prep_covid_atlas.py` |
| `converted/lupus/` | ~90 MB | Lupus SLE PBMC expression + metadata | `python scripts/prep_lupus.py` |
| `converted/smillie2019/` | ~5 MB | Smillie colon expression + metadata | `python scripts/prep_smillie2019.py` |
| `converted/nichenet/` | ~262 MB | NicheNet prior networks (Zenodo 7074291) | Auto-downloaded by `scripts/compare_nichenet.R` |

Also gitignored per-dataset run artifacts (regenerated on each run):
- `results/**/paper_figures/` — per-figure PNGs/PDFs (embedded in NEUROSCOPE_figures.pdf)
- `results/**/poster_figures/` — poster-format figures
- `results/**/ml_models/` — trained model files
- `results/**/networks/` — network export files
- `results/**/statistics/` — per-run stats dumps
- `results/**/novel_discoveries/` — discovery CSVs
- `results/**/*_complete_results.mat` — full MATLAB workspace snapshots
- `results/**/*_run.log`, `results/**/*.log` — run logs

## 4. Large Model Files

| Path | Size | Notes |
|------|------|-------|
| `results/kang2018/Kang2018_complete_results.mat` | ~50 MB | Full MATLAB workspace. Gitignored. |
| `results/covid_atlas/COVIDAtlas_complete_results.mat` | ~200 MB | Full MATLAB workspace. Gitignored. |

These `.mat` files contain the full NEUROSCOPE workspace and can be loaded in MATLAB
to inspect any intermediate variable. They are gitignored because they are large and
fully reproducible by re-running the pipeline.
